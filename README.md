# 📊 Data Analytics Final Project: Telecom Customer Churn Analysis

Official repository for the Data Analytics bootcamp final project, focused on exploring, cleaning, and visualizing the customer churn rate for the fictional company **ConnectTel**, using the classic Kaggle dataset (*Telco Customer Churn*).

---

## 🛠️ Tech Stack & Tools
* **Language:** Python (Pandas) for data ingestion and preprocessing.
* **Database:** PostgreSQL & DBeaver for structured storage and SQL queries.
* **Visualization:** Tableau Public for interactive dashboard development.
* **Version Control:** Git & GitHub.

---

## 📂 Repository Structure
* `data_raw/`: Contains the original raw CSV dataset downloaded from Kaggle.
* `data_clean/`: Stores the processed tables ready for SQL analysis.
* `limpieza.py`: Main Python script for data loading and initial treatment.

---

## 🚀 Project Phases
1. **Phase 1 (Ingestion & Exploration):** Dataset loading via Pandas in VS Code and initial version control setup.
2. **Phase 2 (Cleaning & SQL):** Handling missing values, data type transformations, and relational table splitting for DBeaver.
3. **Phase 3 (Dashboard & Storytelling):** Building KPIs and key metrics in Tableau Public.
4. **Phase 4 (Report & Presentation):** Documentation PDF drafting and project defense.

# 📊 Proyecto Final de Data Analytics: Análisis de Fuga de Clientes (Telecom Churn)

Repositorio oficial del proyecto final del bootcamp de Data Analytics, enfocado en el estudio, limpieza y visualización de la tasa de cancelación de clientes (*Churn*) para la compañía ficticia **ConnectTel**, utilizando el clásico dataset de Kaggle (*Telco Customer Churn*).


---

## 🛠️ Tecnologías y Herramientas Utilizadas
* **Lenguaje:** Python (Pandas) para la ingesta y preprocesamiento de datos.
* **Base de Datos:** PostgreSQL y DBeaver para el almacenamiento estructurado y consultas SQL.
* **Visualización:** Tableau Public para la creación del dashboard interactivo.
* **Control de Versiones:** Git y GitHub.

---

## 📂 Estructura del Repositorio
* `data_raw/`: Contiene el archivo CSV original descargado de Kaggle.
* `data_clean/`: Almacena las tablas procesadas y listas para su análisis en SQL.
* `limpieza.py`: Script principal de Python encargado de la carga y el tratamiento inicial de los datos.

---

## 🚀 Fases del Proyecto
1. **Fase 1 (Ingesta y Exploración):** Carga del dataset mediante Pandas en Visual Studio Code y control de versiones inicial.
2. **Fase 2 (Limpieza y SQL):** Tratamiento de valores nulos, transformación de tipos de datos y división en tablas relacionales para DBeaver.
3. **Fase 3 (Dashboard y Storytelling):** Creación de KPIs e indicadores clave en Tableau Public.
4. **Fase 4 (Memoria y Presentación):** Elaboración de la documentación en PDF y defensa del proyecto.
